# My iPhone Giveaway Bot

Telegram-бот для розіграшу iPhone 15 Pro.

Ця версія запускається як Render Web Service через Telegram webhook.
Змінні: BOT_TOKEN, BOT_USERNAME, ADMIN_IDS.
Функції: реферальні квитки, унікальні номери, статистика.
Реальні платежі не підключені.

Увага: без зовнішньої БД SQLite на безкоштовному Render не гарантує збереження даних після перезапуску/перевикатки.
